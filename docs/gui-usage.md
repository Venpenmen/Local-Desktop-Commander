# Local Desktop Commander GUI（M7-B3.1 开发候选）

## 启动

在 Windows 11 上，在项目根目录运行 `scripts\publish-gui.ps1` 构建自包含 win-x64 GUI。构建完成后双击 `scripts\start-gui.bat`。无需额外安装 .NET 运行时。B3 工具检测需要随包保留 `diagnostics/` 辅助脚本及工作区已有 Node.js 和 MCP SDK。GUI 与管理 CLI 使用当前 Windows 登录用户权限，不以管理员身份自动提升。

独立目录运行：`LocalDC.Gui.exe --root "D:\path\to\LocalDC"`。该目录必须包含 `management\LDC-CLI.ps1` 及对应版本和运行文件。界面仅管理明确指定的工作区实例。

## 概览与设置

“概览”默认展示实际运行状态、版本、运行时长、工具数量、文件权限和连接摘要；PID、授权根及实际/目标配置可在详细运行信息中展开查看。服务启动、停止、重启都要求确认。运行中状态与 MCP 就绪状态不是同一概念：以本地就绪字段核实健康状况。

“设置”选择文件模式（14 项）或完整终端模式（21 项），切换 Restricted/Full 文件权限和指定授权目录。终端命令始终使用 Windows 用户权限，文件根限制不适用于终端。Full 只在支持的托管实例开放，本地开发代理禁用。保存变更时先停止、写入目标配置；“保存并启动”接着启动实例。配置 revision 与其他管理端冲突时需要重新读取，绝不盲目重试。

关闭 GUI 不会停止 MCP 引擎；TUI、GUI 和 CLI 使用同一套管理核心，可以交替操作。GUI 每三秒读取一次实际状态。需要重置未保存的编辑内容时点击“读取当前配置”。

## 验证与范围

运行 `dotnet run --project tests\gui-contract -- "项目根目录"` 可验证客户端协议。运行 `node tests\gui-mcp-probe.mjs files` 仅在本地开发代理已启动时执行真实 MCP 工具调用。完整终端模式也须在已授权的隔离实例上运行。自动化回归证据保存在本地 test-runtime，正式服务不可当作测试夹具。

M7-B0～B2 覆盖基础 GUI 管理，B3 增加只读连接诊断和实际工具清单。日志全文、凭据、版本升级及扩展管理仍属于后续 B4～B7。

## B3：连接与工具管理

GUI 提供四个左侧导航页面：**服务概览、连接管理、工具管理、运行设置**。概览默认显示实际运行状态、运行时长、工具预期/实际数量、当前权限和连接摘要；实际 PID、进程启动时间、目标与回滚配置通过“详细运行信息”查看。连接管理显示本地引擎、MCP 协议、公网传输和远程客户端四层状态，健康码及传输细节可展开。工具管理可手动重新检测、搜索名称、按文件/终端/异常筛选。

开发实例在启动、重启或模式切换后，自动调用真实 MCP `initialize` 和 `tools/list`。实际数量来源于当前运行中的实例，预期名称取自同版本引擎的独立目录。检测超时不重启服务；结果与进程身份绑定。公网传输和 ChatGPT/Gemini 的远程可用性需独立验证，GUI 不将本地检测冒充远程成功。

诊断功能默认只读。控制面板沿用 B2 的确认机制执行启动、停止或受控重启。托管 OpenAI 实例可在明确点击“一键诊断”后调用原管理协议的 `diagnose`，local-dev 仅作回环检测。本轮没有凭据输入、版本升级或日志全文查看页面。

专项验证：`node tests/gui-b3-diff.mjs`、`node tests/gui-b3-faults.mjs`、`node tests/gui-b3-modes.mjs`，配合既有 .NET GUI 契约、WPF 离屏及原有管理回归。后续历史调用统计（B6.5）仅记录于 `docs/gui-b3.md`。

## B3.1：外观与信息精简

主窗口默认 960 × 700 DIP，最小 720 × 520。固定左侧图标文字导航；默认只显示核心运行状态、实际/预期工具数、当前文件权限和连接摘要。PID、目标/回滚、四层健康参数及日志位置通过各页的折叠详情查看。进程归属异常及权限配置尚未生效的警告始终可见。工具未检测时显示“—/预期”，不误报为 0 项。

右上角“外观”支持 **跟随系统 / 浅色 / 深色**，切换立即生效，设置保存于当前 Windows 用户的 `%LOCALAPPDATA%\LocalDC\gui-preferences.json`，与服务管理配置分离。系统模式读取 Windows 应用明暗偏好，并在系统主题变化时更新。不使用托盘：关闭 GUI 窗口，MCP 引擎原样继续运行。

轻量动画遵循 Windows 客户端动画偏好。GUI 专属视觉变更不影响 Shared CLI、Restricted/Full 的后端授权、实例锁和 TUI 状态。设计与验证边界参见 `docs/gui-b31.md`。历史调用摘要与独立统计页为 B6.5 规划，当前版本不显示空白入口。
