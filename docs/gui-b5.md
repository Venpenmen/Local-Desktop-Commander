# M7-B5 GUI 版本管理与安全预检

## 项目规范与事实基线

- 开发工作区 `LocalDC-M7-GUI`，工作分支 `feature/management-gui`；B4 基线提交 `2d6e8d73b3fae8ef968e37f6f8379056a51ab967`。
- 按 `AGENTS.md`、`ROADMAP.md`、`STATE.md`、`TASKS.md`、`docs/management-api.md`、`docs/m7-handoff.md`、`docs/gui-design.md`、`docs/gui-b31.md`、`docs/gui-b4.md` 约束执行。B5 不修改公共管理协议、管理版本注册表、引擎、正式服务或 Gemini 工作区。
- 共享 JSON stdio 管理 API v1 实际提供 `versions`、`state`、`config.get`、`select`（带确认和 Revision）、`rollback`（确认）及 `task.get/events/logs`；**不提供** `install`、`download`、`register`、`remove`、完整性/兼容性校验或事务化升级接口。
- 当前实例版本注册表仅包含 `p6`，`rollback` 也指向 `p6`。若回滚记录与目标仅模式不同，GUI 明确提示它是工具模式回滚；两者相同时禁用回滚，不伪造第二个版本或可恢复点。
- 正式发行版本（例如 `v1.0.0`）、内部注册版本标识（`p6`）和 GUI 当前版本三个概念彼此独立。

## B5 已支持的 GUI 端能力

1. 新增左侧“版本管理”第六页，保留 B3.1 固定导航、三种主题、默认窗口与按需展开信息。所有版本名称、工具数及状态均来自共享 `versions` 与 `state`；目标、实际和回滚分离，读取失败时保留错误而非伪报正常。
2. “刷新版本”读取公共 API。已登记的其他版本可通过 `select` 选择；确认弹窗说明对服务进程的影响，重新读取 Revision、实例身份、实际状态和最新版本清单，再调用公共 `select`。不在 GUI 内复制启动、停止、PID 或文件根逻辑。
3. “回滚”仅对公共 `rollback` 中**真实存在且与目标不同**的候选开放；确认后重新核验 Revision、回滚目标及实例身份，公共管理 API 执行后重新读取实际状态和连接诊断。本轮当前单 P6 登记不能实测跨版本成功回滚。
4. “检查发行更新”仅用户显式点击时从 GitHub 官方仓库的 Releases API 读取公开发行信息。超时、有界数据、合法 HTTPS 仓库 URL、版本及预发布语义比较；只读，不自动下载、安装或启停。该检查不把发行号当作内部 `p6` 注册 ID，不宣称可升级。
5. 离线 ZIP 预检仅读取用户选择的本地文件，计算 SHA-256，可与用户提供的可信外部摘要比对；检查归档条目数、解压体积、压缩比、重复路径、盘符、越界路径与软链接。可以取消，**不解压、不安装、不更改实例配置、版本注册表或系统文件**。没有外部 SHA 时标记“未知来源，未验证完整性”。

## B5 需要公共管理维护分支的依赖

以下任务在 `feature/management-gui` 独立支线 **DEFERRED**，不能标 VERIFIED：

- 可下载可信发行资产的认证、下载/断点续传与可信 checksum/清单的绑定（只有公共发行契约确认之后才可标可安装）。
- 临时安装目录、受保护文件清单、原子安装及版本注册接口；公共核心必须确定 manifest schema、哈希验收、配置迁移及路径隔离。
- 真正的跨版本升级事务：安装准备、停止并切换目标、健康与 MCP 验证、失败自动恢复到上一套有效部署。
- 版本删除和历史清理，包括当前/目标/回滚/正在运行版本及归档安全保护。
- 跨版本成功回滚的真实验证：当前仅一个 P6 版本，没有第二个受信任并已注册的版本；模拟夹具只能证明既有协议边界，不可冒充真实升级。

依赖解锁流程：从 `develop` 建公共维护分支、另写公共管理 API 契约及安全测试 → 合入 `develop` → GUI/Gemini 各自同步 → 才开放 GUI 安装/注册/删除按钮。不得在 GUI 直接改 `management/versions.json` 或猜测发布产物目录。当前工作区单版本时，版本 UI 的完整性标签为“尚未校验”，不是“已验证”。

## 分层验收和工程保护

- L0：XAML/Release 构建、Git 文件白名单、打包产物 SHA 与解包完整性。
- L1：`tests/gui-contract` 包含管理注册版本、非法重复数据、SemVer 及离线 ZIP 安全/取消测试；版本条目来自真实 `versions`。
- L2：`tests/gui-visual` 验证 6 页版本导航、实际 P6、无有效跨版本候选、浅深主题和 DPI；`tests/gui-e2e` 复用原真实 GUI 服务变更，不重复新建管理机制。
- L3：按风险复用或复验 `tests/gui-b3-modes.mjs` 文件 14/终端 21 工具，改动没有触及 MCP 引擎；仅隔离 GUI local-dev 测试，完成后恢复原状态。
- L4：win-x64 发行包包含 B5 模块，解包启动离屏窗口、可用 MCP 工具检测，关闭界面不停止服务。
- 正式部署的 `main/v1.0.0` 与运行进程只读保护；Gemini 工作树只读核验。私有测试证据、真实路径及日志保留忽略的 `test-runtime/`，不提交 Git。

## 用户操作指引

进入“版本管理”后可查看已注册目标及回滚记录。点击“检查发行更新”只读取 GitHub 信息；点击“选择 ZIP 并预检”可验证结构并查看 SHA-256（建议输入发布方独立提供的摘要）。此页面没有安装按钮，因为共享管理接口当前尚不支持安全安装；不应把预检当作版本已安装。

有真实已注册的其他版本时，“切换至选中版本”才可用；发生配置冲突时先刷新，不自动重试。只有当已登记回滚候选不同且有效时，回滚按钮才可用。完成切换后转至连接管理核验本地健康与工具列表；实际远程 ChatGPT/Gemini 调用必须另行验证。
