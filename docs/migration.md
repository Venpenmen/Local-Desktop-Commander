# Updates and migration / 更新与迁移

Extract or build into a new directory. Configure the authorized folder and existing tunnel before switching. Stop the previous instance in its own console, confirm exit, then start and test the new one. To roll back, stop the new one before starting the retained installation.

将新版解压或构建到新目录。切换前配置授权目录和已有隧道。从原窗口停止旧实例并确认退出，再启动和验证新版。需要回滚时先停止新版，再从保留的旧安装恢复。
