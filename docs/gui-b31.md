# M7-B3.1 GUI 视觉与信息架构优化

## 决策与范围

B3.1 在 GUI 专属 WPF/.NET 10 层优化，不变更公共 `management/LDC-CLI.ps1` 协议、MCP 引擎、实例进程归属或正式/Gemini 工作区。用户确定：现代管理面板、均衡信息密度、技术详情按需展开、中英混合、浅色/深色/系统跟随、固定图标文字侧栏、默认 960 × 700 DIP、轻量动画、关闭 GUI 不停止 LDC。

保留最小 720 × 520 DIP、三秒状态轮询、确认后启停/重启、Revision 配置冲突、Restricted/Full 权限限制及本地真实工具检测。不得为了视觉简化隐瞒异常、未验证/已过期状态、目标与实际配置差异。

## 视觉资源与层级

- 窗口标题 20 DIP；页面 20；卡片标题 15；核心状态 25～26；正文 13～14；辅助 12。间距按 4/8/12/16/24 DIP，卡片圆角 8，按钮高度 36，导航宽 152。
- 色板由 `gui/ThemeManager.cs` 提供（页面、卡片、侧栏、选中、正文、说明文字、边框、强调、成功、警告、危险）。`DynamicResource` 使切换实时更新；系统模式读取 Windows 当前用户 `AppsUseLightTheme`，监听系统偏好变化。失效/损坏配置回退 System。
- 用户主题偏好只保存在当前用户 LocalAppData 的 `LocalDC/gui-preferences.json`，不修改管理目标配置、实例密钥或公共目录。GUI 关闭不主动请求停止 MCP 引擎。
- 概览默认显示状态/版本/运行时长、启停控制、真实/预期工具数、当前权限及 L1/L2/远程验证摘要。PID、启动时间、回滚、授权根、任务和采样时间置于按需展开区。异常归属或待重启的安全提示始终展示。
- 连接管理按 L1～L4 分层展示，健康码、控制平面、传输能力和日志路径折叠。连接地址仅在现有协议许可的条件下显示/复制。
- 工具管理保持完整实时清单、搜索及分类；设置页保持工具模式、文件权限和授权根配置，目标/回滚明细折叠。
- 默认不增设空白统计页。B6.5 才在首页添加调用次数/成功率/耗时摘要及独立趋势/排名页；不推断模型额度或 Token 数据。

## 操作、缩放与验证边界

- 轻量展开/悬停反馈，不引入框架、长动画、后台驻留或托盘；遵循 Windows 减少动画偏好。窗口可关闭，服务独立继续运行。
- 100%、125%、150% 等比渲染，以及最小尺寸和长路径/工具名显示，记录离屏截图；真实服务/GUI/TUI 状态以独立 CLI 复核。
- B3.1 的发布仅为 GUI 开发候选；不改正式部署。测试只可对隔离 gui/local-dev 实例进行受控变更，finally 恢复初始模式、根目录及运行状态。
- 回归依据 `tests/gui-contract`、`tests/gui-e2e`、`tests/gui-visual`、B3 真实工具模式及管理权限独立验收。结果置于本地忽略的 `test-runtime/`，不将截图、运行路径或私有日志提交公开仓库。
