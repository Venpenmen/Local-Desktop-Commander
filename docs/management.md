# ChatGPT and management / ChatGPT 与管理控制台

Use an existing authorized Secure MCP Tunnel. Configure its ID with scripts/configure.ps1 and save its runtime key using menu 12. In ChatGPT, select the existing tunnel for your custom MCP app. Refresh discovery, check for 14 or 21 tools and perform a real call. An HTTP 200 local health check is separate from hosted discovery.

使用已授权的 Secure MCP Tunnel。用 scripts/configure.ps1 配置 Tunnel ID，通过菜单 12 保存运行密钥。在 ChatGPT 的自定义 MCP 应用中选择该隧道，刷新工具，检查 14 或 21 项并实际调用。本地健康 HTTP 200 与托管发现分别核验。
