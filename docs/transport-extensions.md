# Transport and extension contracts

The management layer owns the Windows operation lock, task state, selected engine and process ownership checks. The transport owns connectivity and the MCP stdio handoff. Engine tools and file policy remain in the engine.

Contract v1 describes the adapter by ID, name, version, transport type, engine protocol, supported operations, configuration types, credential type and configured status, connection and health state. OpenAI is registered in `management/LDC-OpenAI.ps1`. It wraps the existing OpenAI credential, proxy and launcher code. The existing tunnel profile passes the selected mode to the engine. The process observer verifies executable path, command-line arguments, process birth and PID file before stopping it. Health requests are loopback-only and their listening PID must match. Use the existing redacted log/event mechanisms for operator diagnostics.

Future adapters should provide an equivalent descriptor, validated settings, readiness and connectivity observations, log and diagnostic hooks, and start/stop hooks coordinated by the shared manager. Credentials stay internal to the adapter. Forward MCP without reimplementing its tools. Register a new trusted implementation through the management core after determining its process ownership and isolation requirements. The v1 deployment supports one active OpenAI tunnel. An extension manifest by itself does not register runnable code or imply support for a particular AI client.

The bundled manifest in `transports/openai/manifest.json` is a schema example. It declares `schema`, `id`, `name`, numeric three-part `version`, `type`, compatible `management` protocol, `core` protocol, relative `entry`, declarations for `dependencies`, `permissions`, `capabilities`, `health`, `lifecycle` and a `configuration` descriptor. Registration is built-in and explicit. The parser rejects unsupported protocol versions and traversal-style entries. Parsing metadata grants no permissions. Third-party install, signature verification, lifecycle and updates remain future work.
